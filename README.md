# KUDUY MCP

WordPress plugin that lets Claude manage a WordPress site through the Model Context Protocol, always as a real WordPress user and within that user's permissions. GPL-2.0-or-later.

- Install: download `kuduy-mcp.zip` from the [latest release](https://github.com/kuduyDigital/KuDiagnostics/releases/latest), then Plugins → Add New Plugin → Upload Plugin. Requires WordPress 6.9+ and PHP 8.1+.
- Connect: in Claude, add a custom connector with `https://<your-site>/wp-json/kuduy-mcp/v1/mcp`, choose **Sign in now**, log in to WordPress and approve.

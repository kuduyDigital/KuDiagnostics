# KuDiagnostics — tool reference

Generated by `node scripts/tool-reference.mjs` from the tools registered in the plugin. Do not edit by hand.

182 tools. Scope: `kuduy:read` ⊂ `kuduy:write` ⊂ `kuduy:admin`; `kuduy:code` is separate and exists only with `KUDUY_MCP_ALLOW_CODE_EXEC`. Every tool also checks the WordPress capability of the signed-in user, per object. Tools of plugins that are not active are not listed to Claude.

### `kuduy-site-info` — Site info

Returns the site name, URL, language, timezone, WordPress and KuDiagnostics versions, active theme, and the connected WordPress user with their roles. Call this first to learn what site you are working on.

Scope `kuduy:read` · read only
